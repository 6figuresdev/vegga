What you see is not always what you sign.

A dapp can show “Pay 25 USDC to 0xA11c…” while the wallet is asked to sign a different recipient, a bigger amount, an unlimited approval, another chain, or hidden ETH. Vegga uses Kane CLI to drive the real UI while a test wallet records what is actually signed, then compares the two.

 Evidence

Verification dashboard

Kane runs, screen-versus-signed tables and the screen at the moment of signing.
  1. Kane CLI drives the dapp from a plain-English objective and stores what the screen claims.
  2. A test wallet records every signing request and snapshots the screen at that moment.
  3. Vegga decodes the transaction and flags any mismatch. An agent fixes it, Kane re-verifies.

These pages host the demo dapp and the recorded evidence. To run a verification yourself, clone the repository: the test wallet is injected by the Vegga harness, so a normal browser will ask for your own wallet.
