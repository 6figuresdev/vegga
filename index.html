How it works

One browser. Two witnesses.

Kane CLI and a test wallet share the same Chrome. Kane uses the app like a person. The wallet records what the app really asked for.

Kane drives the real UI

A plain-English objective connects the wallet, fills the form and stores what the screen claims, such as ui_recipient and ui_amount. No selectors to maintain.

A test wallet records the truth

An injected wallet auto-confirms, never broadcasts, and logs every signing request with a screenshot of the page at that exact moment.

Vegga compares and closes the loop

It decodes the transaction or signature and flags every mismatch. An agent fixes the dapp from the evidence and Kane re-verifies the same flows.

What it catches

The ways a signature can lie.

Each check compares the screen, what Kane read, and the signed payload. Findings come with the evidence, not a score.

RECIPIENT_MISMATCH

Lookalike recipient

The signed address is not the one shown, and Vegga names the closest address that is.

AMOUNT_MISMATCH

Wrong units

Decimals or unit mistakes that turn 25 into 25 trillion.

UNLIMITED_APPROVAL_HIDDEN

Unlimited allowance

An approve or permit for everything while the screen shows a small number.

NETWORK_MISMATCH

Wrong chain

The screen says a testnet; the transaction would run on mainnet.

HIDDEN_NATIVE_VALUE

Silent ETH

Native currency attached to a token payment that never mentions it.

BLIND_SIGNATURE

Opaque signatures

personal_sign or eth_sign over bytes no person can read.

PERMIT2 · SPENDER_NOT_SHOWN

“No gas, no approval”

An unlimited Permit2 signature for an address the page never shows.

SLIPPAGE_UNPROTECTED

Zero minimum received

A swap that accepts any price while the screen promises a floor.

SWAP_OUTPUT_REDIRECTED

Redirected output

The swap pays someone other than the connected wallet.

TOKEN_SYMBOL_MISMATCH

Token impostor

The screen says one token; the contract is another.

NFT_APPROVAL_FOR_ALL_HIDDEN

Approve-all for NFTs

Access to every token in a collection behind single-item wording.

AGENT_*

Kane’s reading disagrees

Values Kane read off the screen that contradict what was signed.
